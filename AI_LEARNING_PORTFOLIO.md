# AI Learning & Curriculum Portfolio

**Teresa Zhu — Jarvis Consulting Group**

A selection of curriculum design, teaching, assessment and code artifacts from role-based AI/ML and GenAI education for technical learners entering financial services. This public overview links to code samples already published in my GitHub repositories; additional facilitator materials are available on request.

## Learning design approach

Each module begins with a realistic capstone and uses backward-designed labs, worked examples, reference implementations, and competency assessments. Instructor code and demonstrations support learning; trainees write and defend their own final projects.

## Selected modules

| Module | Focus | Sample capstone |
|---|---|---|
| Introduction to ML in Python | EDA, data preparation, model comparison, explainability | Credit-default prediction using public Home Credit data |
| Introduction to Deep Learning | PyTorch, model training and validation, backtesting | Financial time-series modeling |
| GenAI Application Development | OpenAI API, embeddings, retrieval, agents, evaluation | RAG research agent using public bank filings |
| AI-Assisted Software Development | Code review, tests, AI assistance, provenance | Refactor and test a deliberately flawed example application |
| Intro to ML for Business Analysts | AI/ML literacy, requirements, validation | Credit-scoring requirements and model evaluation |

## Featured work

### 1. OpenAI API and RAG research-agent teaching lab
Two-week module guides learners from source documents to retrieval, grounded answers, tool calling, and evaluation with LLM-as-judge.
- [GenAI project code, demos and README](https://github.com/TeresaZYF/Module-4-GenAI-Project)
- Examples: embedding comparisons; retrieval with ChromaDB; prompting; RAG with LangChain; tool calling; ReAct workflow; evaluation

### 2. Capstone-driven machine learning curriculum
Project-based instruction using public data, notebook exercises and staged deliverables.
- [Machine learning notebooks and teaching code](https://github.com/TeresaZYF/ML_Module1/tree/main/Module_1_intro_to_ML)
- [Deep learning instructor demos](https://github.com/TeresaZYF/ML_Module1/tree/main/Module_2_Deep_learning)

### 3. Evidence of learning
Master Code Review: a live technical conversation in which trainees explain design decisions, debug, and adapt their own code. Scoring covers correctness, code quality, reasoning, live modifications, communication, and awareness of limitations. Facilitator preparation includes practice teaching, observation, feedback, and readiness sign-off.
